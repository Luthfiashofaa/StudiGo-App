# 📚 StudiGo – Aplikasi Manajemen Jadwal Belajar

**StudiGo** adalah aplikasi mobile berbasis **Flutter** yang dirancang untuk membantu pelajar dan mahasiswa dalam mengelola jadwal belajar harian secara efektif. Aplikasi ini menyediakan fitur pengaturan jadwal, pengingat, dan manajemen aktivitas sehingga proses belajar menjadi lebih terorganisir.

---

## 🚀 Fitur Utama

* **📅 Manajemen Jadwal**
  Tambahkan, edit, dan hapus jadwal belajar dengan mudah.

* **⏰ Pengingat**
  Notifikasi otomatis untuk memastikan pengguna tidak melewatkan sesi belajar.

* **📊 Tracking Progress**
  Pantau perkembangan belajar dari waktu ke waktu.

---

## 🛠️ Teknologi yang Digunakan

* **Flutter** (Dart)
* **GetX
* **Supabase**

## 📁 Cara Menjalankan Proyek

1. Clone repository:

   ```bash
   https://github.com/Luthfiashofaa/StudiGo-App
   ```
2. Masuk ke folder proyek:

   ```bash
   cd studigo
   ```
3. Install dependencies:

   ```bash
   flutter pub get
   ```
4. Jalankan aplikasi:

   ```bash
   flutter run
   ```
